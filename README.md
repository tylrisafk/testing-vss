# Hand Tracker
A python-based computer project that captures 21 different hand pinpoints in real time, using OpenCV and MediaPipe.
# Features
- Webcam hand tracking, real-time
- Colorful skeleton overlay
- Built with Python 3.11 and Mediapipe
# How to run
1. Install dependencies: 'pip install opencv-python mediapipe==0.10.14'
2. Run 'sample.py'
